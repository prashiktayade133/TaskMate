# TaskMate — Smart To-Do List

TaskMate is a responsive, browser-based task manager built with HTML, CSS and vanilla JavaScript for the Weeks 3–4 JavaScript assignment.

## Features
- Add tasks with a category and priority
- Mark tasks complete or active
- Edit and delete tasks
- Search by task name
- Filter by status and category
- Live total, completed and remaining counters
- Form validation and duplicate-active-task check
- Persistent tasks using browser `localStorage`
- Responsive layout for desktop and mobile

## Run the project
1. Download or extract the project folder.
2. Open `index.html` in Chrome, Edge, Firefox or another modern browser.
3. Add a task using the form. No server or installation is required.

## Project files
- `index.html` — semantic page structure and form controls
- `style.css` — layout, visual styling and responsive rules
- `script.js` — task logic, DOM updates, events and localStorage
- `README.md` — project guide
- `screenshots/taskmate-preview.png` — project UI preview
- `TaskMate_Project_Documentation.pdf` — submission-ready documentation

## JavaScript concepts demonstrated
Variables, functions, arrays of objects, conditional statements, loops, `filter()`, `map()`, `find()`, `some()`, DOM selection and creation, event listeners, form/input events, JSON and localStorage.

## Notes
Tasks are stored in the current browser on the device where the project is opened. Clearing browser storage or using another browser/device may remove or hide saved tasks. Google Fonts are optional; the page falls back to system fonts when offline.
